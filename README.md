# Employee Management System

This is a simple Java-based command-line application that demonstrates core Object-Oriented Programming (OOP) concepts such as classes, objects, constructors, and encapsulation.

## Features
- **Create Employee:** Add new employees with unique IDs, names, departments, and salaries.
- **Search Employee:** Retrieve employee details using their unique ID.
- **Update Employee:** Modify existing employee information.
- **List Employees:** Display all employees currently in the system.

## How to Run
1. Ensure you have Java installed on your system.
2. Compile the Java files:
   ```bash
   javac Employee.java EmployeeManagementSystem.java
   ```
3. Run the application:
   ```bash
   java EmployeeManagementSystem
   ```
